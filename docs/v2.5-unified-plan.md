# SFG OMR Lab v2.5 alpha — unified local engine

This branch is an incremental integration branch, **not yet a verified release**.
Production remains unchanged.

## Geometric evidence families

- **Corner squares:** inexpensive first quadrilateral candidate.
- **Midpoint squares:** independent candidate when corners are ambiguous.
- **ArUco marker IDs:** rotation and marker-identity evidence; may guide midpoint recovery.
- **QR code:** required sheet-identity gate; decoded at the expected warped-sheet position.
- **Left and right timing tracks:** independent 25+25 positional checks, used to rank candidate warps.
- **Seven-tone grayscale strip:** known-position photometric calibration and supplementary geometric sanity check; never substitutes for QR identity.
- **Page boundary:** recovery-only when printed landmarks cannot yield a verified candidate.

These are multiple sources of evidence inside ONE optical scanning pipeline, not multiple complete scanners. An optional small on-device AI crop classifier is a future benchmark-gated fallback, not part of this alpha.

## First integrated change

The orchestrator now uses `unifiedGeometryPolicy.ts` to stop early only on QR-verified **50/50** timing evidence. It may still retain a 48/50 or 49/50 valid candidate for subsequent processing if no complete candidate is found. This changes the speed/accuracy trade-off and must be benchmarked.

## Required validation before release

1. Run `npm run check` and verify the local build.
2. Test Final Test 1 and all previously saved registration regressions.
3. Verify exact bubble coordinates and compare against a human-reviewed 50-row ground-truth file.
4. Benchmark total latency and registration stage time against v2.3.45 and v2.4.618.
5. Consolidate the research Local-Grid algorithm and strict mark morphology into the production optical pipeline.
6. Evaluate a small local ONNX classifier only on ambiguous crops; do not auto-grade unverified model outputs.

Do not describe this alpha as verified or deploy it to production until these checks pass.
