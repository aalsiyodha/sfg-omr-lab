# v2.5 Local-Grid speed validation

The production grid refinement now uses directly indexed CV_8UC1 grayscale bytes and cached ring pixel offsets, retaining the prior optical acceptance thresholds and the conservative print-ring verification.

The regression suite compares the old accessor path against the new direct byte path on identical synthetic warped grayscale data. CI validation is a correctness gate; actual device latency improvement is pending new 5-second image diagnostic.
