# v2.5 alpha release verification

This document is for the GitHub Pages v2.5 alpha release.

## Verified repository changes
- Production GitHub Pages deployment no longer downloads experimental AI model bundles or builds archived multi-engine scanners.
- The main application removes the comparison page. Research remains in existing feature branches.
- v2.5 geometry waits for QR-verified 50/50 timing before short-circuiting other registration hypotheses.
- The regression suite checks this condition and no longer expects the prior policy function name.

## Not yet verified
- GitHub Pages public deployment and browser cache
- Accuracy on independently human-labeled OMR photographs
- Optical Local-Grid integration or local AI fallback

A working GitHub Pages build is not itself proof that the OMR classifier is correct.
